# Wings Over No Man's Land

Wings Over No Man's Land is a stylized First World War arcade flying game built in Unity.

The game combines fast one-input flying, campaign progression, aircraft collecting, and a charming 1920s–1930s aviation presentation.

## Development

- Unity: `6000.4.7f1`
- Primary scenes:
  - `Assets/Scenes/Menu/Menu.unity`
  - `Assets/Scenes/TestLevel.unity`
- Core input: tap, click, or Space to climb
- Platforms: iOS, desktop, WebGL, and additional Unity-supported platforms

Open this repository as a project in Unity Hub. Unity will regenerate the ignored `Library`, `Temp`, `Logs`, and platform build folders locally.
